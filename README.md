# ゼロショット分類に特化した表現分離に基づく共通空間学習

このリポジトリは、ゼロショット分類（Zero-shot Classification）の精度向上を目的に、画像・音声と言語の共通表現を抽出する新しい共通空間学習手法の実装を含んでいます。

## 研究概要

### 背景と目的
従来の多クラス分類モデルは未知のクラスに対応できず、再学習が必要になるという課題があります。これを解決する「ゼロショット分類」では、画像/音声表現と言語表現の間の類似度を計算することで、未知のクラスを識別します。
しかし、既存の手法（CLIP, CLAPなど）では、類似度計算に不要な情報（固有表現）も含まれており、これがノイズとして働く可能性があります。本研究の目的は、類似度計算を「共通表現（必要な情報）」のみで行うことで、分類精度を向上させることです。

### 提案手法
潜在表現を「共通表現」と「固有表現」に分離し、共通表現に対してのみ軸整合（Axis Alignment）を行う共通空間学習を提案しています。

- **表現分離**: 潜在空間から共通・固有それぞれのMLPを介して分離。
- **4つの損失関数**:
    - $L_{con}$: 言語と音声/画像に拡張したInfoNCE損失。
    - $L_{sim}$: 共通表現同士を明示的に揃え、固有成分を抑制。
    - $L_{diff}$: 固有表現側に混入した共通成分を抑制。
    - $L_{recon}$: 分離による情報損失を抑制するための再構成損失。

### 成果
提案手法は、既存の共通空間学習手法（Baseline）と比較して、音声分野の5つのダウンストリームデータセット（ESC-50, US8K, Beijing Opera, TUT2017, Vocal Sound）すべてにおいて精度を上回ることを確認しました。

## 環境構築・学習の実行

以下の手順で環境を構築し、学習を実行してください。

### 1. 依存パッケージのインストール
```bash
pip install -r requirements.txt
```

### 2. 学習 (Training) の実行
各ディレクトリにある `train.sh` を実行することで学習を開始できます。

```bash
# 音声モデルの学習
cd main_audio
bash train.sh

# 画像モデルの学習
cd ../main_img
bash train.sh
```

### 主要な依存ライブラリ
- Python 3.x
- PyTorch (2.10.0)
- torchaudio / torchvision
- transformers
- librosa
- msclap

## ファイル構成

│   ├── train.py             # 学習スクリプト
│   ├── train.sh             # 学習実行用シェルスクリプト

│   ├── test.sh              # 評価実行用シェルスクリプト
│   ├── datasets/            # 音声データセット定義 (ESC-50, US8K等)
│   ├── model/               # 音声用モデル定義 (CLAPベース等)
│   └── ...
├── main_img/                # 画像モダリティ用
│   ├── train.py             # 学習スクリプト
